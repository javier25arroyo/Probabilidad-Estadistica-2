# Probabilidad-Estadística-2-Container-R
Este es un contenedor para ejecutar el programa R en GitHub Codespaces.

## 🚀 Cómo usar este contenedor

### Opción 1: GitHub Codespaces
1. Haz clic en el botón "Code" en GitHub
2. Selecciona la pestaña "Codespaces"
3. Crea un nuevo Codespace o abre uno existente
4. El contenedor se configurará automáticamente con R y las herramientas necesarias

### Opción 2: VS Code con Dev Containers
1. Instala la extensión "Dev Containers" en VS Code
2. Abre este repositorio en VS Code
3. Presiona `F1` y selecciona "Dev Containers: Reopen in Container"
4. Espera a que el contenedor se construya

## 📦 Contenido del contenedor

El contenedor incluye:
- **R** (última versión estable)
- **Paquetes R preinstalados**: tidyverse (incluye ggplot2, dplyr, readr, etc.), httpgd
- **Extensiones de VS Code**: R Language Support, R Pack
- **Herramientas del sistema**: git, curl, wget, vim, nano

## 🧪 Probar el entorno

Ejecuta el script de ejemplo:
```bash
Rscript ejemplo.R
```

O inicia una sesión interactiva de R:
```bash
R
```
